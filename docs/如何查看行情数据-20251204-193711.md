# 如何查看行情数据 - VeighNa Trader 使用指南

## 问题：页面为什么是空的？

VeighNa Trader 的主界面默认是空的，因为：
1. **需要先连接交易接口**（如CTP）
2. **需要订阅合约行情**才能看到数据
3. 各个组件（行情、委托、成交等）需要数据推送才会显示内容

## 查看行情的步骤

### 步骤1：连接交易接口

**如果已配置账号并自动连接：**
- 查看【日志】组件，等待看到"合约信息查询成功"
- 这表示接口已连接成功

**如果未自动连接：**
1. 点击菜单【系统】->【连接CTP】
2. 在弹出的对话框中填入账号信息
3. 点击【连接】按钮
4. 等待连接成功（查看日志）

### 步骤2：订阅行情

连接成功后，在主界面的【交易】组件中：

1. **选择交易所**
   - 点击【交易所】下拉框
   - 选择交易所（如：CFFEX、SHFE、DCE等）

2. **输入合约代码**
   - 在【代码】输入框中输入合约代码
   - 例如：`IF2506`（股指期货）、`rb2510`（螺纹钢）等

3. **订阅行情**
   - 按**回车键**或点击【订阅】按钮
   - 订阅成功后，合约名称会显示在交易组件中

### 步骤3：查看行情数据

订阅成功后，您可以在以下位置看到行情：

#### 1. 【行情】组件（右侧）
- 显示订阅合约的实时Tick数据
- 包括：最新价、买1-5价、卖1-5价、成交量等
- **数据会实时更新**

#### 2. 【交易】组件（左侧）
- 显示当前订阅合约的深度行情
- 包括：买1-5价量、卖1-5价量
- 可以在此组件进行手动下单

#### 3. 【K线图表】模块（需要安装ChartWizard）
- 点击【功能】->【K线图表】
- 输入合约代码（如：`rb2510.SHFE`）
- 点击【新建图表】
- 可以查看实时K线图

## 如果仍然看不到数据

### 检查1：接口是否连接成功
- 查看【日志】组件
- 应该看到"合约信息查询成功"
- 如果看到错误信息，检查账号配置

### 检查2：是否已订阅行情
- 在【交易】组件中确认已输入合约代码
- 确认按了回车键或点击了订阅按钮
- 订阅成功后，合约名称会显示

### 检查3：是否在交易时间段
- 非交易时间段可能没有行情推送
- 期货交易时间：
  - 日盘：9:00-15:00
  - 夜盘：21:00-次日2:30（部分品种）

### 检查4：CTP Gateway是否安装
```powershell
conda activate vnpyenv
python check_ctp.py
```

如果未安装，需要：
1. 安装Visual Studio Build Tools
2. 运行：`pip install vnpy_ctp`

## 其他可以查看数据的方式

### 1. 使用ChartWizard查看K线图
- 需要安装：`pip install vnpy_chartwizard`
- 需要连接接口并订阅行情
- 可以查看实时K线图表

### 2. 使用DataRecorder录制行情
- 需要安装：`pip install vnpy_datarecorder`
- 可以自动录制Tick和K线数据到数据库
- 录制后可以用DataManager查看

### 3. 使用DataManager查看历史数据
- 需要安装：`pip install vnpy_datamanager`
- 可以查看数据库中已保存的历史数据
- 支持数据导入、导出

## 快速测试

   - 可以查看已保存的数据
