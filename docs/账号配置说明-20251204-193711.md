# VeighNa 账号配置说明

## 一、账号配置存储位置

VeighNa的账号配置信息存储在 **`.vntrader`** 文件夹下的JSON文件中：

- **配置文件位置**：
  - 优先：当前工作目录下的 `.vntrader` 文件夹
  - 备选：用户主目录下的 `.vntrader` 文件夹（如 `C:\Users\YourName\.vntrader`）

- **配置文件命名**：
  - CTP接口：`connect_ctp.json`
  - 多个账号：`connect_ctp_账号1.json`、`connect_ctp_账号2.json` 等

## 二、添加账号的方法

### 方法1：使用工具脚本（推荐）

1. **编辑 `add_accounts.py`**
   - 在脚本中找到 `accounts` 列表
   - 填入您的账号信息

2. **运行脚本**
   ```powershell
   conda activate vnpyenv
   python add_accounts.py
   ```

3. **账号信息格式**
   ```python
   {
       "account_name": "账号1",      # 账号标识名称
       "gateway_type": "CTP",        # Gateway类型
       "username": "123456",         # 用户名
       "password": "your_password",  # 密码
       "broker_id": "9999",         # 经纪商代码
       "md_address": "tcp://180.168.146.187:10131",  # 行情服务器
       "td_address": "tcp://180.168.146.187:10130",  # 交易服务器
       "product_info": "",          # 产品信息（可选）
       "auth_code": ""              # 授权编码（可选）
   }
   ```

### 方法2：通过GUI界面添加

1. 启动VeighNa Trader
2. 点击菜单【系统】->【连接CTP】
3. 在弹出的对话框中填入账号信息
4. 点击【连接】按钮
5. 配置会自动保存到JSON文件

### 方法3：直接编辑JSON文件

1. 找到 `.vntrader` 文件夹
2. 编辑或创建 `connect_ctp.json` 文件
3. 填入以下格式的配置：

```json
{
    "用户名": "123456",
    "密码": "your_password",
    "经纪商代码": "9999",
    "交易服务器": "tcp://180.168.146.187:10130",
    "行情服务器": "tcp://180.168.146.187:10131",
    "产品名称": "",
    "授权编码": "",
    "产品信息": ""
}
```

## 三、多个账号的配置

### 方式1：使用不同的配置文件（推荐）

为每个账号创建独立的配置文件：
- `connect_ctp_账号1.json`
- `connect_ctp_账号2.json`
- `connect_ctp_账号3.json`

然后在代码中为每个账号创建不同的Gateway实例：

```python
from vnpy.event import EventEngine
from vnpy.trader.engine import MainEngine
from vnpy.trader.ui import MainWindow, create_qapp
from vnpy_ctp import CtpGateway

def main():
    qapp = create_qapp()
    event_engine = EventEngine()
    main_engine = MainEngine(event_engine)
    
    # 添加多个CTP Gateway实例，使用不同的名称
    main_engine.add_gateway(CtpGateway, "CTP_账号1")
    main_engine.add_gateway(CtpGateway, "CTP_账号2")
    main_engine.add_gateway(CtpGateway, "CTP_账号3")
    
    # ... 其他代码
```

### 方式2：在GUI中切换

1. 每次只连接一个账号
2. 需要切换时，先断开当前连接
3. 再连接另一个账号

## 四、从C#代码转换账号信息

如果您的C#代码中有账号配置，通常格式如下：

```csharp
// C# 示例
string username = "123456";
string password = "your_password";
string brokerId = "9999";
string mdAddress = "tcp://180.168.146.187:10131";
string tdAddress = "tcp://180.168.146.187:10130";
```

转换为Python配置：

```python
{
    "username": "123456",           # 对应C#的username
    "password": "your_password",    # 对应C#的password
    "broker_id": "9999",           # 对应C#的brokerId
    "md_address": "tcp://180.168.146.187:10131",  # 对应C#的mdAddress
    "td_address": "tcp://180.168.146.187:10130",  # 对应C#的tdAddress
}
```

## 五、常见字段说明

### CTP接口字段

| VeighNa字段 | C#变量名 | 说明 | 必填 |
|------------|---------|------|------|
| 用户名 | username | 交易账号 | 是 |
| 密码 | password | 交易密码 | 是 |
| 经纪商代码 | brokerId | 期货公司代码 | 是 |
| 交易服务器 | tdAddress | 交易服务器地址（含端口） | 是 |
| 行情服务器 | mdAddress | 行情服务器地址（含端口） | 是 |
| 产品名称 | productInfo | 产品信息 | 否 |
| 授权编码 | authCode | 授权码 | 否 |
| 产品信息 | productInfo | 产品信息 | 否 |

### 服务器地址格式

- **格式**：`tcp://IP地址:端口`
- **示例**：
  - 交易服务器：`tcp://180.168.146.187:10130`
  - 行情服务器：`tcp://180.168.146.187:10131`

## 六、验证配置

运行以下命令查看已配置的账号：

```powershell
python add_accounts.py
```

脚本会列出所有已配置的账号信息（密码会隐藏显示）。

## 七、使用配置

配置完成后，在VeighNa Trader中：

1. 点击【系统】菜单
2. 选择【连接CTP】（如果有多个账号，会显示多个连接选项）
3. 在弹出的对话框中，之前保存的配置会自动加载
4. 点击【连接】即可

## 八、注意事项

1. **密码安全**：
   - JSON文件中的密码是明文存储的
   - 请妥善保管配置文件，不要泄露

2. **配置文件位置**：
   - 配置文件不在项目代码目录中
   - 位于 `.vntrader` 文件夹，便于升级时保留配置

3. **多个账号**：
   - 如果需要在同一时间连接多个账号
   - 必须为每个账号创建独立的Gateway实例
   - 使用不同的Gateway名称区分

4. **配置文件格式**：
   - 必须使用UTF-8编码
   - JSON格式必须正确
   - 字段名必须与Gateway要求的完全一致

## 九、获取配置文件位置

运行以下Python代码可以查看配置文件的实际位置：

from vnpy.trader.utility import TEMP_DIR
