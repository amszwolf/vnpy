# VeighNa 运行指南

## 一、环境准备

### 1.1 激活conda环境

```powershell
conda activate vnpyenv
```

### 1.2 验证环境

运行测试脚本验证核心框架：

```powershell
python test_core.py
```

如果看到"所有测试通过"，说明环境配置正确。

---

## 二、运行方式

### 2.1 简化版GUI运行（推荐入门）

**文件**：`run_simple.py`

**命令**：
```powershell
conda activate vnpyenv
python run_simple.py
```

**说明**：
- 启动VeighNa Trader主界面
- 不包含外部Gateway和App（需要单独安装）
- 适合了解框架基本结构

**功能**：
- 显示主窗口界面
- 可以查看系统菜单
- 可以查看功能菜单（但需要安装相应App）

### 2.2 完整版GUI运行

**文件**：`examples/veighna_trader/run.py`

**前置条件**：
需要安装以下模块（通过pip安装）：
```powershell
pip install vnpy_ctp          # CTP交易接口
pip install vnpy_ctastrategy  # CTA策略模块
pip install vnpy_ctabacktester # CTA回测模块
pip install vnpy_datamanager  # 数据管理模块
```

**命令**：
```powershell
conda activate vnpyenv
python examples/veighna_trader/run.py
```

**功能**：
- 完整的交易界面
- 支持连接CTP等交易接口
- 支持CTA策略运行
- 支持策略回测
- 支持数据管理

### 2.3 无界面模式运行

**文件**：`examples/no_ui/run.py`

**适用场景**：
- 服务器端运行
- 自动化交易
- 策略守护进程

**命令**：
```powershell
conda activate vnpyenv
python examples/no_ui/run.py
```

**说明**：
- 需要配置CTP连接信息
- 使用多进程守护模式
- 根据交易时间段自动启动/关闭

### 2.4 图表示例运行

**文件**：`examples/candle_chart/run.py`

**命令**：
```powershell
conda activate vnpyenv
python examples/candle_chart/run.py
```

**说明**：
- 需要数据库中有历史K线数据
- 展示K线图表功能

## 三、典型使用流程

### 3.1 开发策略

1. **创建策略文件**
   - 继承策略基类（如`CtaTemplate`）
   - 实现`on_init()`、`on_bar()`等方法

2. **加载策略**
   - 在VeighNa Trader中通过"CTA策略"模块加载
   - 或通过代码直接加载

3. **运行策略**
   - 连接交易接口
   - 启动策略
   - 监控运行状态

### 3.2 连接交易接口

1. **配置连接信息**
   - 在"系统"菜单中选择"连接XXX"
   - 填写用户名、密码、服务器地址等

2. **连接**
   - 点击"连接"按钮
   - 等待连接成功提示

3. **订阅行情**
   - 在"合约查询"中查找合约
   - 双击合约订阅行情

### 3.3 策略回测

1. **准备数据**
   - 使用"数据管理"模块导入历史数据
   - 或使用"行情记录"模块录制数据

2. **配置回测**
   - 打开"CTA回测"模块
   - 选择策略、合约、时间范围
   - 设置初始资金、手续费等参数

3. **运行回测**
   - 点击"开始回测"
   - 查看回测结果和图表

## 四、常见问题

### 4.1 缺少模块错误

**错误**：`ModuleNotFoundError: No module named 'vnpy_ctp'`

**解决**：
```powershell
pip install vnpy_ctp
```

其他模块类似，根据错误信息安装对应模块。

### 4.2 GUI无法显示

**问题**：在服务器或无图形界面环境中运行GUI程序

**解决**：
- 使用无界面模式（`examples/no_ui/run.py`）
- 或使用SSH X11转发（Linux）
- 或使用VNC等远程桌面

### 4.3 数据库连接错误

**问题**：无法连接数据库

**解决**：
- 检查数据库配置（`vnpy/trader/setting.py`）
- 确保数据库服务已启动
- 检查数据库文件权限
